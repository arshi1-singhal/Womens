# Women Safety System

## About the Project
The Women Safety System is a technology-based solution designed to improve personal safety and provide quick access to emergency assistance. It aims to help women respond to unsafe situations through accessible digital tools and safety features.

## Problem Statement
Women may face unsafe situations where contacting someone or requesting immediate help is difficult. This project aims to provide a simple and accessible safety solution that can help users alert trusted contacts during emergencies.

## Key Features
- **SOS Emergency Alert:** Quickly trigger an emergency alert.
- **Location Sharing:** Share the user's location to help trusted contacts identify their whereabouts.
- **Safety Dashboard:** Access important safety features through a user-friendly interface.
- **Emergency Contacts:** Store or manage trusted contacts for assistance
